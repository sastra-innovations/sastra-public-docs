# Reference Architectures

This directory contains conceptual reference architectures for governed enterprise AI and document intelligence workflows using Medha, MedhaOS and SastraPDF. These patterns are safe for public release and intentionally avoid internal infrastructure topology, credentials, ports, private hostnames, proprietary implementation details and exploitable security configurations.

## Available Reference Architectures

| Reference architecture | Focus |
| --- | --- |
| [Governed Knowledge Assistant](governed-knowledge-assistant.md) | Scoped retrieval and AI-assisted knowledge workflows under identity, RBAC, policy and audit controls. |
| [Governed Document Processing](governed-document-processing.md) | Document extraction, review, transformation and approval-controlled actions. |
| [Private Or Hybrid AI Deployment](private-hybrid-ai-deployment.md) | Conceptual deployment patterns for sensitive enterprise AI workflows. |

## How To Use These Patterns

Use these reference architectures to frame evaluation discussions, design-partner workflows and solution architecture reviews. They are not deployment runbooks and should be adapted to organization-specific systems, security requirements, data classes and approval models.
